# Pollenarium 利用ガイド

[アプリを開く](https://gyroid-eth.github.io/pollenarium/) · [English](user-guide.en.md) · [ドキュメント一覧](README.md)

Pollenariumは、本物の花粉のSEM写真を観察し、球面上の数理モデルで模様を作る実験室です。似ているかは自分で判断します。採点や、生物の物性値を逆算する機能はありません。画面の操作名は日本語中心です。

![Pollenarium observation, calculation and specimen collection](https://github.com/gyroid-eth/pollenarium/releases/download/docs-media-v1/overview.png)

実画面：左が観察するSEM、中央が計算結果、右が条件、下が保存した標本。保存例はこのガイド用に作成。SEM: H. Halbritter / PalDat。 [Image credits](SCREENSHOTS.md).

## 1. アトラスから観察標本を選ぶ

Observeの「52点から選ぶ」で形態アトラスを開きます。学名・和名・属科名を入力するか、「突起」「くぼみ・孔」「溝・帯」「網目」「平滑」「複合粒」で絞り込み、写真を選んでください。「すべて」は形態の絞り込みを解除します。検索語は残るため、必要なら検索欄も空にします。「論文presetあり」は形態フィルタと併用でき、Table 1の分類名に対応する33点だけを表示します。

写真を選ぶと、Observeの画像・学名・日本語の補助表示・撮影者・出典が切り替わります。確認済みの表示推奨和名を併記し、和名が未確認・要確認の種には属や科の仲間名を表示します。名称の出典も参照できます。Wikipediaリンクは対象が種・亜種・属・科のどれかと、日本語・英語の別を表示します。属・科の記事を種の記事としては扱いません。**標本の選択によって計算条件や生成結果がリセットされることはありません。** 計算用プリセットは右側で別に選びます。アトラスを開いている間も実行中の計算は進みます。形を止めて観察したい場合は、先に「停止」を押してください。

「実験へ戻る」またはEscapeでも閉じられます。開くと検索欄へ、閉じると元のボタンへフォーカスが移ります。Tab／Shift+Tabでアトラス内を移動し、Enterで標本を選べます。

分類は見た目から探すための手がかりです。孔や溝には発芽口も含まれ、その形成機構をこのモデルが説明するわけではありません。写真のスケールバーを見てください。画像の表示サイズは物理的な大きさにそろえていません。52点のうち6点は100 µm、46点は10 µmのバーを含みます。

![Pollenarium shape atlas and filters](https://github.com/gyroid-eth/pollenarium/releases/download/docs-media-v1/atlas.png)

52点を一覧で比較し、学名や見た目、論文presetの有無から選びます。SEM: H. Halbritter、W. Oberschneider、B. Diethart / PalDat。 [Image credits](SCREENSHOTS.md).

Table 1との対応表示は「種一致」「異名経由」「綴り要確認」「属のみ」を区別します。「属のみ」は種一致ではありません。また、対応は論文行の係数を探すための分類名リンクであり、選んだSEM写真にその係数が形態フィットしたという意味ではありません。

## 2. モデルを選ぶ

| モード | 何をするか | 主な操作 |
| --- | --- | --- |
| 平衡のかたち / Eq. 6 | 限られた球面調和次数の中で、エネルギーの低い形を探す | l₀、u、rを変え、「この条件で探索する」 |
| 模様の成長 / Eq. 7 | 平均場を保存しながら、球面上で模様が変わる過程を計算する | q₀、τ、u₃、停止時刻tを変え、「この条件で育てる」 |

Eq. 6を選んだときや論文プリセットを読み込んだときは、独自に事前計算した候補が表示されます。これはその場で新しい探索を完了したという意味ではありません。「この条件で探索する」でブラウザ内の新しい計算を始めます。34件のTable 1項目には24組の異なるパラメータがあります。

Eq. 7のタブへ切り替えると、既定条件で時間発展が始まります。論文プリセットを選ぶと、その係数を読み込んで待機します。その間、球体は直前の結果なので、条件と表示を対応させるには「この条件で育てる」を押してください。論文の3プリセットはFig. 2の係数を使いますが、初期場と離散化は独自のものです。

Eq. 7を長時間計算することと、Eq. 6の制限された平衡探索は別の計算です。Eq. 6の反復回数も、Eq. 7の無次元時刻も、生物の実時間ではありません。

## 3. 計算し、見比べる

まず1項目だけ変えて計算し、変化を観察すると比較しやすくなります。「停止」で現在の状態を観察できます。計算中や、まだ計算していない条件へ変更した状態では保存できません。画面のステータスと案内を確認してください。

生成した球体はドラッグで回転でき、マウスホイールで拡大・縮小できます。「凹凸の見せ方」は図示だけを変えます。物理的な壁厚ではなく、SEMを生成する光学・電子顕微鏡モデルでもありません。

![Controls and result of an Eq. 7 growth experiment](https://github.com/gyroid-eth/pollenarium/releases/download/docs-media-v1/growth.png)

Eq. 7の操作例：q₀=1.1、τ=−3、u₃=−8、t=2。論文の図そのものの再現ではなく、自由探索の例です。左のSEMは独立した参照標本です。SEM: W. Oberschneider / PalDat。 [Image credits](SCREENSHOTS.md).

### 主なパラメータ

| 設定 | 意味 |
| --- | --- |
| Eq. 6のl₀ | 使用する次数を決める。整数なら1次数、その間は隣接する2次数 |
| Eq. 6のu | 山と谷の非対称性に関わる無次元の三次結合 |
| Eq. 6のr | 秩序化に関わる無次元係数。論文の相図はr=−1 |
| Eq. 7のq₀ | エネルギーが好む波数。実際に最も成長する球面次数と同一ではない |
| Eq. 7のτ、u₃ | 一様場の不安定性や山と谷の非対称性に関わる係数 |
| seed | 初期配置を決める乱数の種 |
| 初期ゆらぎ・最大次数 | Eq. 7初期場のRMS振幅と、最初に雑音を入れる次数の上限 |
| 平均場・R | 保存される平均と球の半径 |
| L・Δt | Eq. 7の保持次数と時間刻みの上限。数値精度にも影響する |

「初期条件・計算の設定」を開くと詳細を変更できます。Eq. 6には探索する初期配置の数と反復上限もあります。Eq. 7のD=K=1、u₄=120は画面では固定され、保存記録にも含まれます。

## 4. My specimensに残す

計算を終えるか停止し、名前と観察メモを付けて「My specimensに残す」を押します。標本箱には生成画像が並びます。保存は自動ではありません。追加計算や表示変更後に残したい状態も、改めて保存してください。

1件の記録に、モデルと計算法の識別子、全数値係数、パラメータ、seed、実際の停止時刻または探索診断、表示方向・凹凸、生成PNG、観察メモ、参照画像のURLとクレジットが対応付けられます。

「取り出す」で保存した形・条件・表示を復元します。

- **Eq. 7：**「保存時刻から計算を続ける」は、保存した全係数と次の刻みから実際に時間発展を続けます。現在のUIでは、少なくとも保存時刻より2先まで進めます。続行前に条件を変えるとこのボタンは隠れ、新しい条件での計算になります。
- **Eq. 6：**形と条件は復元しますが、探索器の内部状態は再開しません。再探索は保存条件から新しく始まります。
- **旧方式のEq. 7記録：**続行にも元の計算法を使います。新方式へ黙って置き換えません。

## 5. JSONで持ち出す・読み込む

各標本の「JSON」から1件ずつ書き出せます。別のブラウザや端末では「JSONを読み込む」で読み込み、その後「取り出す」を押します。読み込みは新しい記録を追加し、同じファイルを繰り返すと複数件になります。現在の上限は1ファイル20 MBです。

JSONには生成したモデル画像と数値状態が入り、**PalDatのSEM画像そのものは入りません。** 参照先のURLとクレジットは残ります。生成PNGはJSON内に保存されます。報告画面からはPNGだけを取り出すこともできます。

保存先はブラウザのIndexedDBです。アカウントやサーバへの保存、端末間同期はありません。同じ端末でもブラウザ・プロファイル・サイトのオリジン（方式、ホスト名、ポート）が変わると別の保存領域です。`localhost`と`127.0.0.1`、ローカル版と公開デモは別になります。同じオリジンのURLパスだけを変えても、通常は同じ保存領域です。

サイトデータの削除、ブラウザによる容量回収、プライベートブラウズの終了などで記録が失われる場合があります。残したい標本はJSONで書き出してください。ブラウザごとの容量制限もあります。

## 6. 見つけた再現候補を報告する

論文プリセットにない花粉も、条件を探索して結果を報告できます。似ているかは自分で判断します。報告はプレイヤーの再現候補であり、論文プリセットや検証済みの物性値として自動登録されるものではありません。

1. 残したい結果をMy specimensへ保存します。
2. 保存した標本の「この結果を報告」を選び、似ているところ・違うところを書きます。
3. 報告内容を確認し、本文をコピーして、生成PNGと再現用JSONをダウンロードします。JSONには保存時点の全係数と表示条件が入るので、受け取った人がアプリで復元できます。
4. GitHubの投稿画面を開き、案内文をコピーした本文に置き換えます。PNGとJSONを本文欄へ添付して、本人が送信します。GitHubへのログインが必要です。

アプリが自動でIssueを投稿することはありません。ダウンロード対象は選んだ保存標本で、現在操作中の結果ではありません。SEMの画素は添付ファイルに含めず、PalDatの出典リンクとクレジットを残します。GitHubへ送信した内容は公開されるため、入力したメモを確認してください。

[GitHubでの添付方法](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/attaching-files)

## 初期条件と数値精度を扱う

同じseedだけでは条件が同じとは限りません。Eq. 7の初期場は帯域制限した球面調和係数から作り、指定したRMSに正規化します。著者のセルごとの白色雑音とは異なります。seed・平均・RMS・初期帯域をセットで記録してください。

精度を比べるときは、物理係数と初期場と観測時刻をそろえ、まずΔtを小さく、次にLを大きくした結果を比べます。Lを変える際に初期帯域まで変えると、解像度だけでなく別の初期問題を比べることになります。

平均場の保存、エネルギー低下、高次数側のパワーが小さいことだけでは収束を保証しません。模様の大きさや区画数が似ていても、欠陥の位置や場そのものは異なることがあります。Eq. 6も複数の初期配置でエネルギーを比較する必要があり、低い勾配だけで大域最小とはいえません。

[モデルの定義](../MODEL.md)、[到達範囲](../COVERAGE.md)、[同じ初期場での数値診断](../REPRODUCTION_DIAGNOSTICS.md)に、検証済みの条件と残る差分を記録しています。

## 表示や保存で困ったとき

| 状態 | 確認すること |
| --- | --- |
| SEMが表示されない | 画像を同梱しない版は「SEM画像未同梱」と表示します。標本を選び、ObserveのPalDatリンクから原資料を開けます |
| 球体を表示できない | WebGLを利用できるブラウザ・設定か確認します。高解像度では追加の描画拡張が必要な場合があります |
| 計算が重い | 停止し、短い時間や低いLで試します。軽い計算と、精度確認の計算を区別してください |
| 保存ボタンが無効 | 計算中か、条件を変えて未計算の状態です。停止または再計算します |
| 標本が見つからない | 別のブラウザ・プロファイル・オリジンではないか確認し、書き出しておいたJSONを読み込みます |
| JSONが読めない | 現在の形式・モデルに対応するファイルか、20 MB以下かを確認します。任意の古い試作形式には対応していません |
